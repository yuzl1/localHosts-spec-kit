# Contract: LocalHosts 管理块格式

**Feature**: [spec.md](file:///Users/yuzl6/Documents/trae_projects/localHosts-spec-kit/specs/001-hosts-manager/spec.md)  
**Created**: 2026-04-12

## 目的

为系统 hosts 文件提供一个稳定、可识别且可回写的“LocalHosts 管理块”。管理块外内容必须原样保留。

## 边界行

管理块由两条边界行包裹：

```text
# === LocalHosts START ===
...
# === LocalHosts END ===
```

规则：

- START 与 END 行必须独占一行
- 若文件中存在多组边界行，仅第一组视为管理块，其余视为块外内容
- 若边界不完整（只有 START 或只有 END），整段视为块外内容；保存时在文件末尾追加一个新的完整管理块

## 块内内容

块内输出以“分组边界注释 + 逐行条目”组成。条目默认采用“一域名一行”。

### 分组边界注释

管理块内每个分组必须以边界注释包裹：

```text
#######<分组名>开始####
<generated lines>
#######<分组名>结束####
```

规则：

- 分组名使用工作区中的分组名称原样输出
- 分组边界行必须独占一行
- 分组内条目位于“开始/结束”边界行之间
  - 条目仍遵循下文的“一域名一行/整行注释禁用”规则

```text
<ip> <domain> # <comment>
```

条目禁用时，整行注释：

```text
# <ip> <domain> # <comment>
```

规则：

- `comment` 为空时可省略 `# <comment>` 部分
- `domain` 为单个 token（不含空白）；一行多域名输入在工作区中拆分为多条
- 不在块内写入与系统解析冲突的语法

## 纯注释行与禁用条目判定

对 `#` 开头的行：

- 若去掉 `#` 与其后空白后仍可解析为合法条目（IP + 1..N 个域名 token），则视为“禁用条目”
- 否则视为“纯注释行”，块外必须原样保留；块内不生成纯注释行（除非作为固定说明行）
